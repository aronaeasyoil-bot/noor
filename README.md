# NOOR — Travel, Experiences, Beyond

Responsive NOOR travel landing page, ready to publish on Netlify as a static site. The repository was empty when cloned, so this is a polished first public-facing website based on the supplied NOOR travel brief and brand mark.

## Publish

The project has no build step. Set the Netlify publish directory to `.`. The two inquiry forms use Netlify Forms and return to `merci.html` after submission.

## Included

- French, English and Arabic interface copy, with right-to-left direction for Arabic.
- Responsive destination, experience, service and Africa-to-Dubai sections.
- Netlify Forms for trip requests; no live flight, hotel availability or payment integrations are configured.
- Local brand and destination images in `public/images`.
